# portfolio W.I.P

New Moon Mining Company (newmoonmining.co): Jack Bowman portfolio, work in progress.

- Open index.html in a browser. Scroll to send the menu words out of the bag; scroll back to put them away.
- ✥ (bottom right) lets you drag the words and export their positions.
- Aa (or the backtick key) opens the dev panel: typeface, scale, layout, palette, with separate horizontal and vertical layouts.
- ✎ toggles content editing: text and images, contents only.
